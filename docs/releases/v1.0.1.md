# Iris 1.0.1

Minecraft **1.21.1** · NeoForge **21.1.248** · Java **21**

## Fixes

- Fixed the recipe catalogue search fields so focused input consumes keyboard shortcuts. Pressing **E** now types in the active search field instead of closing the inventory.
- Search fields now lose focus when clicking elsewhere, restoring normal inventory keybind behavior.
- Fixed the Gradle data-generation run for ModDevGradle 2.x by using the supported `data` run type.

## Installation

Download `iris-1.0.1.jar` and place it in the compatible instance's `mods` folder. Install Iris on both client and server for multiplayer.
